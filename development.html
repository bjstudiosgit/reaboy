Built from 256 bytes
of original 1989 silicon.

ReaBoy was engineered through byte-level reverse engineering starting at byte $0000 of the canonical 1989 Nintendo DMG-01 boot ROM. We disassembled and proved all 121 Sharp SM83 instructions across 38 basic blocks with zero byte mismatches, creating a cycle-accurate SM83 CPU, scanline PPU, 4-channel APU, and native WinMM desktop architecture.

PHASE 01 · STATIC REVERSE ENGINEERING

Byte-Identical Boot Reconstruction

A custom Sharp SM83 disassembler and control-flow graph builder accounted for every single byte of the 256-byte DMG-01 boot ROM — then reassembled it with RGBDS v1.0.4 and proved 0 byte mismatches. Bundled directly inside the ReaBoy package as open-source Bootix DMG v1.2.

HARDWARE SPECIFICATIONS

DMG-01 Memory Map & Silicon Architecture

Bit-exact memory map and hardware register allocation implemented inside ReaBoy's MemoryBus.cs and Sm83Cpu.cs.

Memory Range Size Bus Destination Hardware Role & Emulation Handling
$0000–$00FF 256 B Boot ROM / Cart ROM Overlayed during boot execution. Unmapped permanently when $01 is written to register $FF50.
$0000–$3FFF 16 KiB Cartridge ROM Bank 00 Fixed ROM bank from cartridge. Contains interrupt vectors ($0040–$0060) and game entry point ($0100).
$4000–$7FFF 16 KiB Switchable ROM Bank Bank-switched via cartridge mapper (MBC1, MBC2, MBC3). Controls up to 2 MiB of commercial Game Boy ROM data.
$8000–$9FFF 8 KiB Video RAM (VRAM) Character tile patterns ($8000–$97FF) and Background Tile Maps ($9800–$9BFF and $9C00–$9FFF).
$A000–$BFFF 8 KiB External Cartridge RAM Battery-backed game save state and scratch RAM. Gated by RAM Enable register ($0A).
$C000–$DFFF 8 KiB Work RAM (WRAM) Internal 8 KiB onboard static RAM for game variables, call stacks, and dynamic buffers.
$FE00–$FE9F 160 B Sprite Attribute Table (OAM) 40 hardware sprite definitions (Y, X, Tile Index, Flags). Evaluated during PPU Mode 2 OAM search.
$FF00–$FF7F 128 B I/O Registers (MMIO) Hardware controls for Joypad, Serial, Timers, 4-Channel APU audio, PPU LCDC/STAT, and Boot unmap.
$FF80–$FFFE 127 B High RAM (HRAM) Zero-page ultra-fast internal CPU RAM used for OAM DMA transfer routines and high-frequency state.
$FFFF 1 B Interrupt Enable (IE) Bitmask enabling VBlank (bit 0), LCD STAT (bit 1), Timer (bit 2), Serial (bit 3), and Joypad (bit 4).
