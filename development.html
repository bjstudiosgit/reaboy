Dual Game Boy & Color Memory Map Architecture

Bit-exact memory map, banking controllers, and hardware register allocations implemented inside ReaBoy's MemoryBus.cs, CgbRegisters.cs, and Sm83Cpu.cs. Select between DMG-01 monochrome, CGB-001 dual-bank, and low-level color I/O registers.

Memory Range Size Bus Destination Hardware Role & Emulation Handling
$0000–$00FF 256 B Boot ROM / Cart ROM Overlayed during boot execution. Unmapped permanently when $01 is written to register $FF50.
$0000–$3FFF 16 KiB Cartridge ROM Bank 00 Fixed ROM bank from cartridge. Contains interrupt vectors ($0040–$0060) and game entry point ($0100).
$4000–$7FFF 16 KiB Switchable ROM Bank Bank-switched via cartridge mapper (MBC1, MBC2, MBC3). Controls up to 2 MiB of commercial Game Boy ROM data.
$8000–$9FFF 8 KiB Video RAM (VRAM) Single 8 KiB bank. Character tile patterns ($8000–$97FF) and Background Tile Maps ($9800–$9BFF and $9C00–$9FFF).
$A000–$BFFF 8 KiB External Cartridge RAM Battery-backed game save state and scratch RAM. Gated by RAM Enable register ($0A).
$C000–$DFFF 8 KiB Work RAM (WRAM) Internal 8 KiB static RAM for game variables, stack pointers, and dynamic buffers ($C000–$CFFF Bank 0, $D000–$DFFF Bank 1).
$E000–$FDFF 7.5 KiB Echo RAM Mirror of internal RAM $C000–$DDFF. Accesses in ReaBoy forward transparently to WRAM.
$FE00–$FE9F 160 B Sprite Attribute Table (OAM) 40 hardware sprite definitions (Y, X, Tile Index, Flags). Evaluated during PPU Mode 2 OAM search.
$FF00–$FF7F 128 B I/O Registers (MMIO) Hardware controls for Joypad ($FF00), Serial ($FF01–$02), Timers ($FF04–$07), 4-Channel APU ($FF10–$FF3F), and PPU LCDC/STAT ($FF40–$FF4B).
$FF80–$FFFE 127 B High RAM (HRAM) Zero-page ultra-fast internal CPU RAM used for OAM DMA transfer routines and high-frequency state.
$FFFF 1 B Interrupt Enable (IE) Bitmask enabling VBlank (bit 0), LCD STAT (bit 1), Timer (bit 2), Serial (bit 3), and Joypad (bit 4).
Memory Range Size Bus Destination (CGB-001) CGB Hardware Role & Emulation Handling
$0000–$08FF 2,048 B (2 KiB) CGB Boot ROM / Cart ROM 2 KiB color bootstrap ROM overlaid at boot. Unmapped permanently when $01 written to $FF50.
$0000–$3FFF 16 KiB Cartridge ROM Bank 00 Fixed ROM bank from cartridge. Contains CGB cart header ($0134–$014F) and game entry point ($0100).
$4000–$7FFF 16 KiB Switchable ROM Bank Bank-switched via MBC1, MBC2, MBC3, MBC5, or MBC7. Supports up to 8 MiB of Game Boy Color cartridge ROM.
$8000–$9FFF 16 KiB (Dual Bank) Banked Video RAM (VRAM) Switched via $FF4F (VBK): Bank 0 = 8 KiB Character Tiles; Bank 1 = 8 KiB Tile Color Attributes (Palettes 0–7, VRAM bank select, priority, horizontal/vertical flip).
$A000–$BFFF 8 KiB External Cartridge RAM / RTC Battery-backed game save SRAM, Real-Time Clock registers (MBC3), or Accelerometer EEPROM (MBC7).
$C000–$CFFF 4 KiB Work RAM Bank 0 Fixed internal 4 KiB RAM bank mapped permanently into address space.
$D000–$DFFF 32 KiB (7 Banks) Switchable Work RAM (WRAM) Switched via $FF70 (SVBK): Selects Bank 1 through 7 into the 4 KiB window (total 32 KiB internal Work RAM for fast CGB double-buffered variables).
$E000–$FDFF 7.5 KiB Echo RAM Mirrors WRAM $C000–$DDFF. Handled transparently in ReaBoy's MemoryBus dispatch.
$FE00–$FE9F 160 B Sprite Attribute Table (OAM) 40 hardware sprites with extended CGB Byte 3 flags: Palette 0–7 select, VRAM Bank 0/1 select, priority, and mirroring.
$FF00–$FF7F 128 B CGB I/O Registers (MMIO) Includes KEY1 ($FF4D double-speed), VBK ($FF4F), HDMA ($FF51–55), Palette RAM ($FF68–6B), and SVBK ($FF70).
$FF80–$FFFE 127 B High RAM (HRAM) Zero-page fast RAM executed during DMA transfers and critical hardware synchronization loops.
$FFFF 1 B Interrupt Enable (IE) Master interrupt enable register (VBlank, STAT, Timer, Serial, Joypad).
Register Name Access Hardware Function & ReaBoy Silicon Implementation
$FF4D KEY1 R/W Prepare Speed Switch: Bit 7 indicates current CPU speed (0=Normal 4.194 MHz, 1=Double 8.388 MHz). Bit 0 arms speed toggle executed upon next STOP instruction.
$FF4F VBK R/W VRAM Bank Select: Bit 0 selects active Video RAM bank (0 or 1) mapped into $8000–$9FFF. Bank 0 holds tile patterns; Bank 1 holds palette and attribute maps.
$FF51–$FF52 HDMA1–2 W New DMA Source Address: High & Low bytes specify ROM or RAM source ($0000–$7FF0 or $A000–$DFF0) aligned to 16-byte boundaries.
$FF53–$FF54 HDMA3–4 W New DMA Destination: High & Low bytes specify VRAM destination ($8000–$9FF0) aligned to 16-byte boundaries.
$FF55 HDMA5 R/W DMA Length / Mode / Start: Configures transfer block size (16 to 2,048 bytes) and mode: Bit 7=0 (General DMA: copies entire block instantly); Bit 7=1 (H-Blank DMA: copies 16 bytes per horizontal blanking interval).
$FF68 BCPS R/W Background Palette Specification: Bits 0–5 index color bytes 0–63 (8 palettes × 4 colors × 2 bytes). Bit 7 enables Auto-Increment after every write to $FF69.
$FF69 BCPD R/W Background Palette Data: Read/write byte to 15-bit RGB555 palette RAM. Two consecutive byte writes define 1 color (5 bits Red, 5 bits Green, 5 bits Blue).
$FF6A OCPS R/W Object / Sprite Palette Specification: Bits 0–5 index sprite palette bytes 0–63 with optional Auto-Increment (bit 7).
$FF6B OCPD R/W Object / Sprite Palette Data: Read/write sprite 15-bit RGB555 palette RAM for hardware sprites 0–39.
$FF70 SVBK R/W WRAM Bank Select: Bits 0–2 select Work RAM bank 1 through 7 mapped into $D000–$DFFF (values 0 and 1 both map Bank 1). Total 32 KiB internal RAM.

Why Choose ReaBoy?

  • Zero Setup Overhead: Download the ZIP, extract anywhere, and drag-and-drop your ROM. No installation wizards, no administrator privileges required.
  • No BIOS Search: Bundled with CC0-licensed Bootix DMG v1.2 firmware out of the box.
  • Pure 1989 Hardware Purism: Focused purely on authentic original DMG-01 monochrome gameplay without convoluted multi-system menus.
  • Clean Educational C# Architecture: Engineered with modern C# and published transparently for researchers and emulation enthusiasts.

When to Use SameBoy

  • macOS Native Experience: First-class native Cocoa frontend with Metal acceleration on macOS.
  • Instruction Breakpoint Debugging: Powerful integrated assembly debugger, memory inspector, and VRAM viewer for reverse engineers.
  • Extensive Peripheral Emulation: Excellent Game Boy Camera, Barcode Boy, and WorkBoy support.
  • Official Site: sameboy.github.io ↗

When to Use BGB

  • Homebrew Production: BGB is universally revered as the benchmark tool for developing new Game Boy software.
  • Exhaustive Hardware Profiler: Trace execution cycles, inspect register state, and benchmark instruction timings.
  • Link Cable Emulation: Excellent TCP/IP and local link cable multiplayer emulation support.
  • Official Site: bgb.bircd.org ↗

Verification Methodology & Transparency

ReaBoy v2.0 is validated through an extensive automated testing harness with 184 unit tests and 63 hardware acceptance suites:

1. 63 / 63 Passing Hardware Test ROMs

Every release passes 16 Blargg CPU/timing/halt_bug suites, 37 Mooneye-GB acceptance & MBC2 tests, 2 Matt Currie Acid2 tests (dmg-acid2 and cgb-acid2 with 0/23,040 pixel diff), and 8 MagenTests CGB suites.

2. 1,592 Headless ROM Regression Runs

Automated 240-frame headless execution across the entire 1,592 commercial Original Game Boy library, verifying memory bus reads, opcode traps, timer ticks, and boot stability.

3. Controlled Commercial Cartridge Matrix

600–900 frame telemetry verification across 19 commercial cartridges spanning Category A (DMG), Category B (Dual $80), and Category C (CGB $C0), running at 1,020–1,354 FPS with zero heap allocations per frame.
