ReaBoy User Manual

Official technical reference for Windows 10/11 x64 · Cycle-accurate DMG-01 architecture, keyboard controls, Bootix firmware, and CLI flags.

1. Quick Start & System Requirements

Open ReaBoy.exe. No separate .NET installation and no administrator rights are required. The application starts directly on the no-cartridge logo screen using the bundled open-source Bootix firmware (unless File > Skip Intro is checked).

  • Load a game: Drag and drop any .gb ROM onto the ReaBoy window, choose File > Open ROM (Ctrl+O), or pass the file path on the command line.
  • OS requirement: Windows 10 or Windows 11 (64-bit x64).
  • Audio requirement: Standard Windows WinMM audio output device.
  • Commercial games: Game ROMs are not supplied. Keep your legally owned dumps in the rom/ folder or open them from any directory.

2. Production Package Contents

The portable ZIP distribution (ReaBoy-v1.0.1-win-x64.zip) contains:

  • ReaBoy.exe — Standalone application with bundled .NET 8 runtime and embedded Bootix DMG v1.2 & CGB boot firmware.
  • README.md — Bundled quick guide, controls reference, and version details.
  • LICENSES.txt — Application copyright and complete Microsoft .NET runtime licence notices.
  • rom/ — Open-source Bootix boot ROMs (dmg_boot.bin and cgb_boot.bin), BOOTIX-LICENSE.txt (CC0-1.0), and ROM instructions.

The runtime unpacks native components into the standard per-user .NET temporary cache when needed. Nothing needs to be written beside ReaBoy.exe.

3. Menus, Video & Audio

  • Emulation > Remove Cartridge: Safely flushes battery-backed MBC1 RAM and returns to the empty-console boot logo.
  • Emulation > Reset: Restarts the inserted cartridge (or the empty-console logo).
  • Speed & Execution: Pause / Resume, Normal Speed (1×), and Fast Forward (targets 3× speed depending on host CPU; intentionally mutes audio).
  • Video: Fixed integer 1×, 2×, 3×, and 4× scales locked to the native 160 × 144 aspect ratio (capped automatically to fit your monitor), Fullscreen (F11), and Classic Green or Grayscale palettes. Stretched or maximized window states are rejected to keep pixels razor-sharp.
  • Audio: Enable/Mute toggle and persistent volume control over native WinMM output.
  • Recent Games: Remembers up to 10 recently opened ROM paths.

5. Boot Firmware & Dual Bootix Engine (Game Boy & Color)

ReaBoy includes built-in open-source boot engines for both original Game Boy (DMG-01 · 256 Bytes) and Game Boy Color (CGB-001 · 2,048 Bytes). Both firmware routines are embedded directly inside ReaBoy.exe and bundled in the portable rom/ directory using Bootix (CC0-1.0 Public Domain). No external BIOS dumps or copyrighted files are required—ReaBoy is 100% legal and playable out of the box.

Game Boy (DMG-01) Firmware 256 BYTES

Memory range: $0000–$00FF. Executes CPU stack initialization, 8 KiB VRAM zeroing, 4-channel APU startup, scrolling logo decompression, and header checksum verification before unmapping at $FF50.

Default: rom/dmg_boot.bin (or embedded Bootix DMG v1.2)
Game Boy Color (CGB-001) Firmware 2,048 BYTES

Memory range: $0000–$08FF. Manages 2× speed CPU negotiation, VRAM/WRAM banking registers, 15-bit RGB palette generation, cartridge mode detection ($80 dual vs $C0 CGB-only), and post-boot handoff.

Default: rom/cgb_boot.bin (or embedded Bootix CGB)

Firmware Resolution Priority

When launching any ROM, ReaBoy automatically detects whether the title requires DMG or CGB firmware, then resolves the active boot image in this strict order:

Priority Boot Source Behavior & Custom ROM Compatibility
1 · Highest Custom User Boot ROM
File > Choose Boot ROM...		 Loads any custom 256-byte DMG or 2,048-byte CGB binary. Supports genuine dumped Nintendo boot ROMs with original scrolling animation and chime sound.
2 · Portable Adjacent rom/ Folder
rom/dmg_boot.bin or rom/cgb_boot.bin		 Automatically loaded if present beside ReaBoy.exe. Allows simple portable drop-in replacements without reconfiguring menus.
3 · Safe Fallback Embedded Bootix Firmware
Compiled inside ReaBoy.exe		 Guarantees 100% plug-and-play operation even if portable files are missing. Zero configuration or setup needed.

Fast Boot & Skip Intro

Enable File > Skip Intro (or use the --skip-intro command-line flag) to bypass the scrolling boot animation entirely. ReaBoy will jump immediately to cartridge entry point $0100 within 0 milliseconds, with all Sharp SM83 registers (AF, BC, DE, HL, SP) and hardware I/O registers precisely initialized to exact post-boot silicon values.

6. Battery Saves & Settings

  • Settings file: %APPDATA%\BJStudios\ReaBoy\settings.json
  • Battery RAM folder: %APPDATA%\BJStudios\ReaBoy\saves\

Unreadable or corrupted settings files are automatically backed up and restored to safe defaults. MBC1 battery-backed RAM is saved automatically on game changes, resets, cartridge removal, and exit. Save filenames are keyed by a hash of the ROM contents to prevent filename collisions across regional revisions.

7. Command-Line Interface & Headless Mode

ReaBoy supports automated launching and headless frame benchmarking directly from the Command Prompt, PowerShell, or Windows Terminal:

CLI USAGE EXAMPLES 
ReaBoy.exe [game.gb] [--scale 1..8] [--bootrom path] [--boot | --skip-intro]
ReaBoy.exe game.gb --headless --skip-intro --frames 600

9. Hardware Models & Cartridge Compatibility

Supported Hardware Models

  • Original Game Boy (DMG-01): Authentic monochrome Sharp SM83 CPU, scanline PPU, 4-channel APU, and 1,592 of 1,592 original Game Boy commercial titles (100% Playable).
  • Dual Game Boy & Game Boy Color ($80): Switchable between 15-bit CGB colour and authentic monochrome DMG mode via Emulation > Hardware Mode (e.g. Tetris DX, Zelda: Link's Awakening DX, Pokémon Gold/Silver, Wario Land II).
  • Game Boy Color Exclusive ($C0): Full CGB hardware exploitation with 2× double-speed CPU (8.388 MHz), 16 KiB banked VRAM, 32 KiB banked WRAM, HDMA/GDMA, and custom RGB555 palettes (e.g. Pokémon Crystal, Zelda: Oracle of Ages/Seasons, Super Mario Bros. Deluxe, Kirby's Tilt 'n' Tumble).

Supported Cartridge Mappers

  • ROM-Only: Standard 32 KiB cartridges.
  • MBC1: Up to 2 MiB ROM and 32 KiB battery-backed RAM.
  • MBC2: Built-in 512×4-bit internal RAM and battery saves (e.g. F-1 Race).
  • MBC3: Full hardware Real-Time Clock (RTC) latching and battery saves (e.g. Pokémon Red, Blue, Yellow, Gold, Silver, Crystal).
  • MBC5: Up to 8 MiB ROM and 128 KiB RAM with rumble and battery saves (e.g. Zelda: Oracle of Ages, Oracle of Seasons, Wario Land 3, Pokémon Pinball).
  • MBC7: Accelerometer analog tilt controls and 93LC56 SPI EEPROM (e.g. Kirby's Tilt 'n' Tumble).
  • HuC1 & HuC3: Infrared transceiver and command parser with RTC/EEPROM (e.g. Pocket Family GB2).
